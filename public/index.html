Data Rules

Confirmed means a visible deer in the actual image. Listing text alone never creates an observation.

True positives are stored historically. Photos are only permanently re-hosted when the source license permits it; otherwise retain observation metadata, hashes, embeddings, source URL and listing reference.

Harvest status is unknown, reported or verified. Never infer harvest because a deer stops appearing.
