# Deer Identity, Phenotype, Genetics, and Harvest

## Identity
Persistent IDs use visual re-identification: antler configuration, scars, ear damage, markings, body traits, geography and time. Automated matching is a candidate identity, not proof.

## Genetics
Do not call image similarity genetics. Store phenotype and lineage hypotheses separately. True genetics require DNA or verified pedigree evidence.

## Harvest
States: `unknown`, `alive_recent`, `reported`, `verified`. Verified status should have evidence such as a matched harvest image, hunter confirmation, date/location, or voluntarily supplied lawful harvest record. Never infer harvest from disappearance.
